CapyBun Dungeon Adventure

Project Overview:

Our project is a game level for an asynchronous puzzle game where players swap between Capybarda and Spellbun to solve puzzles, overcome obstacles, reunite, and escape the dungeon together.

This project was developed as a Group Project for Digital Portfolio at the University of Florida’s Digital Worlds Institute.
